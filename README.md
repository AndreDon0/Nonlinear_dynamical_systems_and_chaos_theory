$$
\begin{pmatrix} \dot{x}  \dot{y}  \dot{z} \end{pmatrix}

0 & -1 & 0

### Домашняя работа №3 — Одномерное дискретное отображение: бифуркации и показатель Ляпунова

- Построить график зависимости показателя Ляпунова от параметра $r$.
- Для выбранных $r$ найти стационарные точки и рассмотреть их устойчивость (в т.ч. численно, например методом Ньютона).

### Домашняя работа №4 — Фрактальные размерности сечения Пуанкаре

**Файл:** `[Homework_4.ipynb](Homework_4.ipynb)`

**Подробное условие:** `[dz4 fractal dimension.pdf](files/dz4%20fractal%20dimension.pdf)`

**Вариант:** 7

**Система** (численное решение — по материалам [задания №2](Homework_2.ipynb)):

$$\dot{x} = -z,\quad \dot{y} = -x^2 - y,\quad \dot{z} = 1.7 + 1.7x + y$$

**Цели работы:**

- По набору точек пересечения траектории с плоскостью $y = 0$ оценить **ёмкостную (box-counting) размерность**, **корреляционную размерность** и **размерность Каплана–Йорка**.

- Обсудить согласованность результатов трёх методик, оценить влияние шума на две из них и сформулировать краткие выводы.
